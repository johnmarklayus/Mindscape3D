# Screens and Menus

How the dialogue box, menus, journal and every other screen are made.

Every screen is a UXML file in `Assets/UI Toolkit/`, listed in `Resources/EpisodeUI.asset`. The main menu is `MainMenuNew.uxml`, which holds every menu page. Edit layouts in **Window › UI Toolkit › UI Builder**. Controllers look up elements by `name`, so keep names unchanged when you restyle a screen. On mobile, a touch overlay and a pause button are added while the game runs.
