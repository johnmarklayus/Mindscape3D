# Plan an Episode

Decide these first so names and save keys stay consistent.

| Field | Example |
|---|---|
| Chapter and episode number | Chapter 4, Episode 1 |
| Title | First Steps |
| Where it happens | Joey's house at night, the school, the reunion hall, the street |
| What the player does, in order | Arrive → talk to Mom → choose a reply → breathing → go to bed |
| Saved choices | Stable keys such as `ch4_reply` |
| Next destination | The next episode's scene, or the main menu |

Keep to the [Writing Guidelines](/#story-tone).
