# QA Test Cases

All QA reports live in one workbook: `Documents/Reports/MindScape QA Master.xlsx` (it opens in Excel, Numbers or Google Sheets).

- **Masterlist** (first sheet): every report with its case count, Pass / Fail / Blocked / Not run counts, pass rate and overall status, then every test case with its status, tester, date and notes. It is all formulas: change statuses on the report sheets, never here.
- **One sheet per report**: ID, test case, preconditions, steps, expected result, and the yellow columns testers fill in (Status as a dropdown, Tester, Date tested, Actual result / notes). Each sheet also has a cell for the build or version tested.
- **_Template**: a blank report sheet with one example row.

## Adding a report

The workbook is generated by `Tools/QA/qa_master.py`. A report script (for example `Tools/QA/add_ch3_ending.py`) lists its sheets and cases and calls:

```python
from qa_master import load, add_report, rebuild_masterlist, save
wb = load()
add_report(wb, "Sheet name", "Report title", "Scope", [("ID-01", "Test case", "Preconditions", "Steps", "Expected result")])
rebuild_masterlist(wb)
save(wb)
```

`add_report` leaves an existing sheet of the same name untouched, and `rebuild_masterlist` only rewrites the Masterlist, so testers' entries are never lost. Run it with `python3` from `Tools/QA/`.

> [!TIP] Testing a plan in Chapter 1 Episode 4
>
> Episode 4 reads the Episode 1 laptop choice from the save. To test plan A or B, play Chapter 1 Episode 1 to the laptop decision and pick it, then open Episode 4. A profile with no choice follows plan A.
